Dayline 是一款原生 Mac 应用。它把今天的选择、你要的结果，和还在生长的想法放在同一个窗口里。它不催你做更多。它帮你把有限的时间留给值得的事。

> **当前源码已包含：**「每日回顾」让你在一天结束时，用自己的语言整理学到的内容、看见真实进展，并把一个思考带到明天。每个日历日只有一份回顾，输入会自动保存；旅行或切换时区不会改变历史日期。Today 有轻量入口，已有回顾也可通过原导出中心按单日或多日导出。代码已经合并到 `main`，但尚未建立新的稳定版本 Tag。

<a id="why"></a>

## 为什么是 Dayline

三件本来连在一起的事，常常被拆开。

今天做的事，和长期方向对不上。你很忙，却说不出这一周是在靠近什么。

一个念头出现的时候没有地方放。等你想起它，已经不知道当时为什么重要。

任务都勾完了，事情本身可能还停在原地。完成和做成，不是同一件事。

Dayline 不打算替你变成更高效的人。它让这三处断裂，在同一个窗口里重新看得见。

<a id="philosophy"></a>

## 三个判断

### 今天，由你来选

昨天没做完的事，不该自动变成今天的全部。

在「今天」里，计划在今天、或今天到期的事，按 Learning、Research、Health 放在一起。更早没完成的计划停在「待重新安排」。那里写着：之前的计划还在这里。选择今天，或给它一个新的日期。

今天因此是一次选择，不是欠账的堆积。

每天或每周要重复的事，做完这一次，会接上下一次。错过的那些天不会一次补回来。

### 进度，是结果，不是勾选

目标可以是一个长期方向，也可以是它下面的短期成果。

成果进度由你自己拨。编辑目标时写着：由你根据实际成果更新。完成任务不会自动改变这个百分比。旁边另有一行，是关联行动完成了多少。两件事都在，谁也不冒充谁。

### 灵感，可以慢慢长

不是每个想法都该马上变成任务。

在「灵感」里，你可以写下还没有答案的问题，把它挂到一个领域或一个目标上，也可以只是放着。写下去的时候，它会自动保存。

等它成熟，点「转为任务」。原来的灵感还在。新的任务先不排期，由你决定哪一天做。删掉灵感，也不会带走已经生成的那条任务。

<a id="day"></a>

## 一天里的 Dayline

你在学一门要花几个月的课。先写下长期目标：「把这门课真正学完。」再在它下面放一个短期成果：「这个月读完指定的四章。」成果进度留在你觉得真实的位置，而不是任务勾了多少。

早上打开「今天」。上一天没读完的章节停在「待重新安排」。你把其中一章选进今天，其余的改到后面。只想起一个名字、还不知道放哪的事，可以先留在收件箱。

读的时候冒出一个还说不清的问题。你把它记在「灵感」里，挂到这门课的目标上，先不排期。

几天后，问题清楚了。你点「转为任务」。灵感还在原处。新任务还没有日期，你再决定它哪一天做。

这一周想留一份纸面的计划，按 `⇧⌘E`，导出 PDF、PNG 或 Markdown。

在「今天」页往下打开「计划记录」，能看见这些天计划了什么、实际完成了什么、哪些是当天新加的、哪些是你主动改期的。它不会替你改任务。有效计划日还不到 7 天时，不会出现容量建议；够了之后，「今天」里可能多出一条建议，你也可以把它关掉。

侧边栏底下有一行小字：每一天，都算数。

<a id="install"></a>

## 安装

Dayline 在你自己的 Mac 上从源码构建。还没有带 Developer ID 的安装包，也没有经过公证的 DMG。你不需要会编程，也不需要付费的 Apple 开发者账号。

需要 macOS 14 或更新版本，以及 Git。构建用 Xcode，或 Xcode Command Line Tools。应用会装到 `~/Applications/Dayline.app`。

<a id="install-ai"></a>

### 交给 AI

这是最省事的办法。在你自己的 Mac 上打开 Cursor、Codex，或其他能在本机执行命令的编程助手，把下面这段整段复制进去。

助手需要有在这台 Mac 上运行命令的权限。如果还没有开发工具，它应该先说明，等你同意再安装。如果已经装过 Dayline，替换应用之前它必须先问你。它不能改动或删除你的正式数据，不能关闭 macOS 的安全保护，也不能向你要 Apple ID 密码。

```text
请在我这台 Mac 上安装 Dayline。

项目地址：https://github.com/dushiye/Dayline

先阅读 README_CN.md、docs/INSTALL_WITH_AI.md 和 AGENTS.md，再按文档做。
我不会编程。请用我能看懂的话说明每一步。
需要安装开发工具时，先告诉我并等我同意。
如果这台 Mac 上已经有 Dayline，替换前先问我。
不要打开、修改或删除 ~/Library/Application Support/Dayline 里的数据。
不要关闭系统的安全保护，也不要向我要 Apple ID 密码或付费开发者账号。
不要在我的正式数据上运行测试。
装好以后告诉我应用在哪里、怎么打开、以后怎么更新。
```

给助手看的完整步骤在 [docs/INSTALL_WITH_AI.md](docs/INSTALL_WITH_AI.md)。

<a id="install-manual"></a>

### 自己在终端里安装

```bash
git clone https://github.com/dushiye/Dayline.git
cd Dayline
scripts/check-environment.sh
scripts/build-macos.sh
scripts/install-macos.sh "$HOME/Applications/Dayline.app"
open "$HOME/Applications/Dayline.app"
```

`scripts/check-environment.sh` 检查 macOS 版本、Swift 和开发工具。`scripts/build-macos.sh` 只构建。`scripts/install-macos.sh` 会再次按当前源码构建，然后把应用复制到你给出的路径。

也可以在 Finder 里双击 `安装 Dayline.command`。已经装过时，终端会先问你，再按当前源码重新构建。

### 更新

在克隆下来的目录里：

```bash
git pull
DAYLINE_REPLACE_INSTALLED=yes scripts/install-macos.sh "$HOME/Applications/Dayline.app"
```

安装脚本会先编译刚刚拉下来的源码，再把原来的 `Dayline.app` 改名留在旁边。你的计划、目标和灵感留在原来的数据库里，安装过程不会读取或改写它。

<a id="privacy"></a>

## 数据在你这里

默认数据库是：

```text
~/Library/Application Support/Dayline/Dayline.store
```

不需要账号，也没有订阅。Dayline 不使用 CloudKit。Mac 和 iPhone 之间目前不会自动同步。

想另留一份，用侧边栏底部「…」菜单里的「导出备份…」。那是一份可读的 JSON，请放在你信任的地方。「从备份恢复…」会先请你确认，因为那是用备份替换当前的全部内容；替换前，应用会先自动留下一份恢复前的备份。

<a id="faq"></a>

## 常见问题

### Dayline 免费吗？

免费。应用里没有广告，也没有内购。代码以 [MIT](LICENSE) 开源。

### 我不会编程，能安装吗？

可以。用上面的提示词，交给一台能在你的 Mac 上执行命令的编程助手。它会检查环境、取得源码、构建并安装。

### 需要付费的 Apple Developer 账号吗？

在自己的 Mac 上构建和安装，不需要。准备好 Xcode 或 Command Line Tools 即可。

### 支持哪些 macOS？

macOS 14，以及之后的版本。

### 能在 Windows 上使用吗？

不能。这是 macOS 应用。

### 数据保存在哪里？

`~/Library/Application Support/Dayline/Dayline.store`

### 更新会不会弄丢我的计划？

不会。更新换掉的是应用。旧的应用会改名留下。数据库不在安装步骤里被读取或改写。重要的内容，仍建议用「导出备份…」另存一份。

### iPhone 版能用吗？

仓库里有一个实验性的 iPhone 应用。它需要用 Xcode，在你自己的设备上签名后安装。目前适合每天使用的是 Mac 版。

### Mac 和 iPhone 能同步吗？

不能。两边的数据各自留在各自的设备上，目前不会自动同步。

### 怎样备份或卸载？

备份用「导出备份…」。卸载时把 `Dayline.app` 移到废纸篓。数据文件夹还在 `~/Library/Application Support/Dayline/`。确认不再需要这些内容之后，再删除那个文件夹。
